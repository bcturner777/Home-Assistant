# Roadmap

## Phase 1: Pilot at home (Raspberry Pi)
- [ ] Home Assistant OS running on the Pi, with backups on
- [ ] Remote access through Home Assistant Cloud
- [ ] Ping + Speedtest internet monitoring
- [ ] Aladdin Connect garage
- [ ] Nest thermostat and doorbell
- [ ] First dashboard: climate, garage, doorbell, internet status
- [ ] Phone alerts: garage left open, internet down, temperature out of range

## Phase 2: Meraki and internet health
- [ ] Custom Meraki integration: device health, client counts, guest SSID toggle
- [ ] WAN loss/latency and an outage log

## Phase 3: Rentals
- [ ] Home Assistant Green at the first rental, using the config from this repo
- [ ] Per-property settings kept in one place
- [ ] `fleet/` multi-property dashboard (status, energy/HVAC runtime, issues)
- [ ] Guest modes tied to the booking calendar, plus vacancy setbacks

## Later
Lighting, smart locks with per-guest codes, irrigation, TVs.
